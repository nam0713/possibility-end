# 가능성의 끝 — v8.1

## 로컬 SF UI 개편 · 2026-10-03

표지는 좌측 산세리프 제목, 우측 우주 링, 8개 장의 선택 목록으로 구성합니다. 번호와 선택 표시는 실제 3D 노드에 연결되며 장 선택은 목차의 미리보기와 동기화됩니다. 목차·장 도입·설정 화면에도 같은 서체와 색을 적용했습니다. `src/observatory.css`가 마지막 스타일 레이어입니다.

구문 검사, 정적 빌드, 원고/HTML 일치 검사를 통과했습니다. 브라우저에서 1440×900, 390×844, 320×568 배치, 장 선택·읽기 연결, 독서 테마, 설정, 엔딩 진입과 위치 복귀를 확인했습니다. 실제 휴대폰·Safari 검증은 수행하지 않았습니다. 원고와 음원은 유지하며 **배포하지 않았습니다**.

미리보기: `http://localhost:5173/#home`. 조사 자료와 적용 기록은 `design/SCI-FI-REFERENCES.md`, `design/SF-REVISION.md`에 있습니다.

브라우저 코멘트 반영: 큰 작품 소개를 간결한 푸터로 합쳤습니다. 본문 기본 서체를 고딕으로 통일하고, 장 도입과 강조 문장의 색을 현재 독서 테마에 맞췄습니다. 강조 문장의 색 테두리는 제거했습니다. 저장된 서체의 일회 전환과 이후 수동 선택 유지, 세 가지 독서 테마, 데스크톱·모바일 푸터를 확인했습니다. 이번 수정도 **배포하지 않았습니다**.

## 로컬 UI 개편 · 2026-10-03

현재 작업 폴더에는 아직 배포하지 않은 UI 개편본이 있습니다. 표지와 장 목록의 서체·여백을 정리하고, 설명 문구·중복 레이블·장식 화살표를 줄였습니다. 탐색 및 독서 설정은 테두리 없는 텍스트 컨트롤로 바꿨습니다. `src/ui.css`를 마지막에 합성하며, 원고·음원과 우주/엔딩의 렌더링은 유지합니다.

`npm run dev`로 로컬 미리보기를 실행합니다. 운영 사이트에 반영하려면 별도의 배포 요청이 필요합니다.

v8에서 변경한 표지 구도를 되돌린 소규모 수정본입니다.

## 이번 변경

제목·구조물 분리 그리드를 제거하고 v7의 제목 위치, 전체 화면 구조물 구도와 크기를 복원했습니다. 기본 표지에서만 구조물의 중심을 아래로 **24 CSS px** 이동합니다. 새로운 영역·여백 섹션을 만들거나, 제목 또는 구조물을 축소하지 않습니다. 우주 탐색 모드의 구도는 기존 그대로입니다.

v8의 네이티브 세로 스크롤 우선 처리, 스크롤 중 렌더링 일시중단, 캔버스 크기 갱신 최적화와 입력 처리 개선은 그대로 유지했습니다. 원고·음원·엔딩·독서 기능 코드는 수정하지 않았습니다. 변경한 런타임 파일은 `src/cosmos.js`와 `src/mobile.css`뿐입니다.

## 실행 및 빌드

`index.html`을 브라우저에서 열거나 `dist/index.html`을 정적 호스팅에 배포합니다. 하나의 HTML에 기존 음원과 소설이 내장되어 있습니다. 기존 운영 주소는 변경하지 않았습니다.

```sh
npm run dev
npm run check
npm run build
```

Node.js 18 이상. 추가 npm 의존성 없이 빌드합니다. Google Fonts를 불러오지 못하면 시스템 서체를 사용합니다. 폰트 파일은 포함하지 않습니다.

## 확인한 범위

320×568, 390×844, 844×390, 1440×900에서 v7과 비교했습니다. 제목·표지 크기·구조물의 가로 위치·원근 배율·스크롤 길이는 같으며 기본 구조물의 세로 위치만 24px 달라집니다. 고리·은하와 탐색 모드를 각각 확인했습니다. 모바일 터치 스와이프에서 v8의 스크롤 우선 처리와 렌더 정지/재개가 유지되는지도 확인했습니다. 33개 항목을 통과했습니다.

검사는 Chromium + Xvfb + SwiftShader에서 최종 HTML을 `set_content`로 넣어 수행했습니다. 시스템 대체 서체를 사용했고, 실제 휴대폰·Safari의 성능을 검증한 것은 아닙니다. `tests/patch-checks.json`은 이번 검사, `tests/patch-scope.json`은 변경 범위, `tests/changes-from-v8.diff`는 실제 코드 차이입니다. `design/restored-*.png`는 수정본의 실제 렌더링입니다.
