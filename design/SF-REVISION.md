# SF UI 개편 · 2026-10-03

## 적용

- 표지: 좌측의 산세리프 제목과 우측의 우주 링. 차가운 백색과 아이스 시안. 읽기 동작은 각진 채움 버튼 하나로 강조합니다.
- 장 탐색: 첫 화면에 8개 장을 배치합니다. 실제로 투영된 3D 노드들을 연결하는 선과 선택 원을 사용합니다. 의미 없는 좌표나 상태 수치는 추가하지 않았습니다.
- 선택 상태: 선택한 장의 번호, 제목, 읽기 링크를 표시합니다. 목차의 모델과 제목도 같은 장으로 바뀝니다. 해제·형상 변경·탐색 종료 시 선택 표시가 함께 초기화됩니다.
- 목차: 큰 모델과 정렬된 장 목록. 표지·장 도입·대화상자에는 산세리프를 사용합니다. 본문 서체 선택은 유지합니다.
- 모바일: 4열 2행의 장 선택, 44px 이상의 터치 영역, 작은 화면의 링 크기 조정, 상하 safe area를 고려한 배치.
- 독서: 종이 테마의 실제 배경색을 복원하고 밝은 테마에서 키보드 초점의 대비를 보완했습니다. 엔딩 연출과 음향 소스는 유지합니다.

## 파일

`src/observatory.css`를 마지막에 합성합니다. `src/shell.html`에는 장 궤도 SVG, 표지 메타데이터와 목차 미리보기 제목을 추가했습니다. `src/cosmos.js`는 홈 구도·선택 표시, `src/app.js`는 선택과 목차 미리보기의 연결을 담당합니다. `build.mjs`에서 새 스타일을 읽습니다. 생성된 `index.html`과 `dist/index.html`을 갱신했습니다.

## 확인

### 브라우저 코멘트 반영

- 큰 `작품` 소개 영역과 반복 설명을 제거했습니다. `#about`은 작품명·장르·장 수만 담은 푸터로 연결됩니다. 데스크톱 높이 112px, 모바일 높이 92px이며 가로 넘침이 없습니다.
- 독서 본문 기본 서체를 UI와 같은 고딕체로 통일했습니다. 구버전 저장값은 한 번 고딕으로 전환하며, 이후 사용자가 명조를 선택하면 그 선택은 재방문에도 보존됩니다.
- 장 도입의 작은 제목은 현재 독서 테마의 보조 글자색을 사용합니다. 이전 테마의 별도 색상 규칙이 적용되지 않습니다.
- 본문 강조 문장은 본문과 같은 크기·색을 사용하며, 색 테두리와 들여쓰기를 없앴습니다. 굵기와 문단 여백으로만 강조합니다.
- 1장과 7장에서 실제 본문/강조 색의 일치, 종이·밝게·어둡게 테마, 수동 서체 선택 후 새로고침, 작품 링크 이동과 390×844 모바일 푸터를 확인했습니다.
- 구문 검사·빌드·원고 일치 검사 통과. 원고 8개 장·215개 블록과 음원의 해시가 유지됩니다. 배포하지 않았습니다.

### SF 개편 확인 기록

- 구문 검사, 정적 빌드, 기존 원고/HTML 일치 검사 통과.
- 8개 장, 215개 원고 블록과 기존 음원 유지.
- 1440×900, 390×844, 320×568에서 표지·장 선택·조작부 배치 확인. 작은 화면의 조작 버튼은 44×44px, 장 선택 행 높이는 44px 이상입니다.
- 장 선택 → 해당 장 읽기, 긴 마지막 장 제목, 목차 미리보기 동기화 확인.
- 독서 설정, 종이/어두운 테마 전환 확인. 종이 배경 rgb(236,235,231), 본문과 초점 색 rgb(36,36,36).
- 마지막 장 엔딩 진입과 Escape 복귀 확인. 주소를 유지하고 scrollY 14839와 실행 버튼 포커스로 정확히 복귀했습니다.
- 실제 휴대폰과 Safari는 검증하지 않았습니다. safe area 배치는 코드 검토로 보완했습니다.
