# UI 개편 · 2026-10-03

요청: 설명 문구와 테두리 버튼을 줄이고 UI를 개편. 배포 보류.

표지, 목차, 장 제목, 대화상자의 서체와 여백을 책의 구성으로 맞췄습니다. 목차는 장 번호와 제목만 표시하며, 중복 소개·설정 안내·장식 화살표를 제거했습니다. 탐색·서체·화면 선택은 테두리 없이 텍스트 색과 짧은 밑줄로 상태를 나타냅니다. 모바일 목차에서는 장 목록을 먼저 보여줍니다. 작품 소개는 한 문단으로 축약했습니다.

`src/ui.css`가 마지막 CSS 레이어입니다. 원고와 음원은 기존 배포본과 SHA256이 동일합니다. 우주 및 엔딩 렌더링 코드는 유지하며, `src/cosmos.js`는 선택한 장 번호와 접근성 안내의 문구만 바꿨습니다.

검증: JavaScript 구문 검사, 정적 빌드, 기존 원고/HTML 일치 검사를 통과했습니다. 로컬 브라우저에서 1440×900, 390×844, 320×568 화면을 확인했고, 장 이동·책갈피·글자 크기·서체·테마 변경·우주 탐색·엔딩 열기와 독서 위치 복귀를 확인했습니다. 실제 휴대폰이나 Safari 검증은 수행하지 않았습니다.

운영 사이트에는 반영하지 않았습니다. 로컬 미리보기: `http://localhost:5173/`.
