# LAST LIGHT — 가능성의 끝

『가능성의 끝』의 마지막 항성과 새로운 우주를 각색한 3D 생존 액션 게임입니다. 마지막 정비 드론 LL–01으로 고장 난 보안 기계를 해체하고, 물질을 회수하고, 세 릴레이를 가동한 뒤 엔트로피 수호체를 넘어 새 우주로 마지막 빛을 보냅니다.

## 실행

상위 폴더에서 `npm run game` 후 [게임 열기](http://localhost:5173/game/). Node.js 18 이상과 WebGL 2를 지원하는 Chrome/Edge가 필요합니다. 기본 플레이는 데스크톱 마우스·키보드 기준입니다. 터치 환경에는 이동 조이스틱, 자동 조준, 발사·돌진·충격파·작동 버튼이 나타납니다.

Three.js와 모든 게임 그래픽·효과음을 로컬에 포함합니다. 그래픽은 절차적으로 생성하고 효과음은 WebAudio로 합성합니다. 선택적 Google Fonts가 연결되지 않아도 시스템 글꼴로 실행됩니다. 게임 실행을 위한 npm 설치는 필요 없습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 | 조준 |
| 왼쪽 버튼 누르기 | 연속 발사 |
| Space | 짧은 무적 돌진 |
| Q / 오른쪽 버튼 | 충격파, 주변 적에게 피해를 주고 적 탄환 제거 |
| E | 가까운 릴레이·설계 보관함·우주 씨앗 작동 |
| 1 / 2 / 3 | 강화 선택 |
| Esc | 일시정지 / 재개 |

## 한 판의 흐름

적을 해체하면 청록색 물질 조각이 나옵니다. 가까이 다가가 회수하면 자원과 경험치를 함께 얻습니다. 레벨이 오르면 시간이 멈추고 무작위 강화 세 가지 중 하나를 고릅니다. 공격력·연사·다중탄·연쇄·지원 드론 등을 중첩해 빌드를 만듭니다.

릴레이 가동에는 차례로 물질 18 / 36 / 54가 필요합니다. 가동한 릴레이의 빛나는 원 안에 있어야 충전이 진행됩니다. 원을 벗어나도 진행도를 잃지 않지만 충전은 멈춥니다. 충전 완료 시 선체 30을 회복하고 주변 물질을 회수하며 추가 강화를 얻습니다. 설계 보관함에도 물질을 투자해 강화를 더 얻을 수 있습니다.

시간과 릴레이 진행에 따라 적이 강해집니다. 세 릴레이를 충전하면 중앙에 최종 수호체가 나타납니다. 방사형 탄막과 미리 표시되는 폭격을 피하며 해체한 뒤 중앙의 우주 씨앗에서 E를 눌러 완주합니다. 탐사/붕괴 두 난이도가 있으며 사망 또는 완주 후 바로 재시작할 수 있습니다.

## 조사와 각색

주요 구조는 Risk of Rain 2의 시간 압박과 아이템 중첩·장치 방어에서 가져왔고, Outer Wilds의 유한한 우주 이미지와 SUPERHOT의 시각적 위협 구분을 참고했습니다. 상용 게임의 코드나 에셋은 가져오지 않았습니다. 렌더러는 MIT 라이선스의 Three.js 0.186.1입니다. 라이선스 전문은 `vendor/THREE-LICENSE.txt`에 포함합니다.

[레퍼런스 조사](../design/GAME-REFERENCES.md), [원작 각색 메모](../design/GAME-STORY-NOTES.md). 적대 보안 기계와 보스는 전투를 위한 게임용 각색입니다.

## 빌드와 검증

상위 폴더에서 `npm run check:game`, `npm run test:game`, `npm run build:game`. 전체 `npm run build`에도 게임이 포함됩니다. 정적 호스팅은 `dist/` 전체를 사용하면 원작 읽기 링크까지 유지됩니다. `file://` 대신 HTTP 서버를 사용하세요.

엔진 갱신이 필요할 때만 이 폴더에서 `npm ci && npm run vendor`를 실행합니다. `?qa=1`은 통합 검사용 브리지를 노출하며 일반 게임 주소에는 노출하지 않습니다. 브라우저 통합 검사 결과는 `../tests/game-browser-results.json`에 기록합니다.
