# 가능성의 끝 — v6

한 편의 소설, 하나의 우주. `index.html` 하나로 실행합니다.

## 실행

`dist/index.html`을 브라우저에서 열거나 정적 호스팅에 업로드합니다.
HTML 안에 그래픽, 원고, 두 음원이 포함되어 있습니다. 외부 서버나 음원 API가 필요하지 않습니다.
Google Fonts는 선택적으로 불러옵니다. 연결이 없으면 시스템 서체로 표시됩니다. 폰트 파일은 포함하지 않았습니다.

소스 수정 후:

```bash
npm run build
npm run dev
```

로컬 주소는 `http://localhost:5173`입니다. Node.js 18 이상으로 빌드하며 외부 npm 패키지는 사용하지 않습니다.
`npm run check`로 JavaScript 문법을 검사합니다.

## 이번 변경

- 엔딩 소개 카드와 ‘엔딩 감상’ 바로가기, 여러 설명 문구를 제거했습니다. 8장의 마지막에는 **‘단 하나의 가능성.’과 빛**만 남습니다. 문장 또는 빛을 누르면 이어집니다. 강한 연출이 스크롤만으로 갑자기 자동 실행되지는 않습니다.
- 새 문서로 이동하지 않습니다. 마지막 빛의 화면 좌표를 이어받아 글이 물러나고 같은 점에서 우주가 펼쳐집니다. 닫을 때는 반대 방향으로 수렴하며 원래 위치와 키보드 초점을 복원합니다.
- 입장 약 2.1초, 복귀 약 1.7초. 화면 밝기만 바꾸는 것이 아니라, 공유하는 광점 위치·카메라 배율·본문 깊이·텍스트·음량을 함께 움직입니다. 전환 도중 취소와 중복 입력도 처리합니다.
- 엔딩의 안내형 단계 번호와 대기 화면을 없앴습니다. 감상 중 조작 UI는 잠시 뒤 옅어지고, 포인터·터치·키보드를 사용하면 돌아옵니다. `Esc`로 언제든 읽던 곳으로 복귀합니다.
- 장 이동도 이전 화면이 나간 뒤 다음 화면이 부드럽게 들어옵니다. 목차, 선택 상태, 설정창, 이전/다음 이동 영역은 같은 테마 변수를 사용합니다. 종이·밝게·어둡게 설정을 따라갑니다.
- 사운드 기본 상태는 켜짐입니다. 소리 버튼을 누르면 음소거와 볼륨 조절이 가능합니다. 명시적으로 음소거한 경우 다른 장이나 엔딩이 소리를 다시 켜지 않습니다.
- 원고 8장/215개 텍스트 블록과 v5 음원 2개는 바이트 단위로 동일합니다. 검증 해시는 `tests/content-integrity.json`에 있습니다.

## 사운드 자동 재생

브라우저가 소리 자동 재생을 허용하면 곧바로 앰비언트가 흐릅니다. 제한하면 별도의 ‘사운드 켜기’ 절차 없이 첫 클릭·터치·키보드 조작에서 오디오 컨텍스트를 재개합니다. **사용자 조작 전의 소리 재생을 모든 브라우저에서 강제로 보장할 수는 없습니다.**

사운드 허용이 지연되거나 Web Audio를 사용할 수 없어도 독서와 엔딩 그래픽은 계속 동작합니다. 특히 **소리를 잠금 해제하기 전에 음소거했을 때도 영상 시간이 멈추지 않도록** 분리했습니다. 다시 켜면 현재 장면 시간에 맞춰 음악을 시작합니다.

음량, 참여 횟수, 엔딩 감상 여부는 저장하지 않습니다. 읽던 위치, 책갈피, 독서 설정만 기존 브라우저 저장소를 사용합니다.

기술 참고:
- MDN Autoplay guide: https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay
- MDN AudioContext.resume: https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume
- MDN HTMLDialogElement.showModal: https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal

## 모션과 접근성

기기의 ‘움직임 줄이기’를 사용하면 폭발 연출 대신 정지 장면을 부드럽게 표시합니다. 자동 점멸을 추가하지 않았습니다. 엔딩은 모달의 키보드 초점을 유지하고, 닫을 때 기존 초점으로 돌아갑니다. 엔딩 참여 기록이나 영구적으로 남기는 빛은 없습니다.

화면이 숨겨지면 사운드와 그래픽 작업을 중단합니다. WebGL을 사용할 수 없으면 Canvas 2D 대체 표현을 사용합니다. 느린 WebGL 장치에서는 입자 수를 유지하면서 렌더 해상도를 자동 조정합니다. 대체 표현은 WebGL 성운과 동일한 세부 효과를 제공하지는 않습니다.

## 파일 구성

- `src/manuscript.txt` — 소설 원고
- `src/app.js` — 독서, 목차, 라우팅, 키보드/저장 관리
- `src/cinematic.js` — 장면 연결과 공유 광점 전환
- `src/ending.js` — 실시간 빅뱅/성운 렌더러
- `src/cosmos.js` — 표지와 장별 공간 그래픽
- `src/audio.js` — 기본 켜짐, 사용자 입력 잠금 해제, 음악/영상 시간 동기화
- `src/cinematic.css` — 통합 테마, 간소화된 UI, 장면 연결 스타일
- `assets/audio/` — 기존 원본 음원 두 개
- `tests/` — 검사 스크립트와 실제 결과
- `design/` — 브라우저 캡처와 디자인 변경 기록

## 검증 범위

검사는 Chromium에서 완성 HTML을 직접 로딩하여 수행했습니다. 실행 환경의 브라우저 정책상 localhost URL 탐색은 차단되어, 테스트는 `set_content`로 정확히 같은 HTML을 주입합니다. Node 로컬 서버의 파일 제공도 별도로 확인합니다.

320 / 390 / 768 / 1440 / 1920px 뷰포트는 브라우저 에뮬레이션이며 실제 휴대폰 테스트가 아닙니다. 자동 재생이 차단된 상황은 제어된 AudioContext로 추가 모사합니다. WebGL은 별도 headed Chromium/소프트웨어 렌더러로 검사합니다.

실제 iOS Safari, Android 기기별 오디오 정책·스피커·GPU, 장시간 실행, 호스팅 환경의 보안 헤더는 검증하지 않았습니다. 수치 및 통과 여부는 `tests/v6-report.json`과 추가 결과 파일을 확인하세요. 테스트 숫자를 디자인 품질이나 실제 기기 성능 보증으로 사용하지 않습니다.

운영 중인 기존 웹사이트에는 업로드하거나 덮어쓰지 않았습니다.

### 최종 확인

본문/이동/테마/오디오/전환 검사 **65/65**, 별도 headed WebGL 검사 **8/8**을 통과했습니다. 테스트에 사용된 HTML 해시는 `tests/VALIDATION.json`에서 확인할 수 있습니다. 실제 기기 및 Safari 테스트는 포함하지 않습니다.

별도로 제공하는 전환 미리보기 MP4는 브라우저가 그린 장면을 같은 전환 시간으로 샘플링한 무음 영상입니다. 실제 사이트에는 사운드가 포함됩니다. 미리보기의 프레임 수는 기기 성능 측정치가 아닙니다.
