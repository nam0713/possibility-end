# v6 연출 변경

소설이 끝난 뒤 다른 기능을 실행하는 듯한 안내를 없애는 것이 목적입니다.

8장 말미의 별도 카드와 엔딩 바로가기 대신 짧은 문장과 광점만 둡니다. 원고를 수정하거나 마지막 실험의 장면을 다시 쓰지는 않았습니다.

전환의 출발점은 버튼의 광점이 실제로 놓인 화면 좌표입니다. 같은 점을 전체 화면 렌더러의 중심으로 전달합니다. 독서 영역이 옅어지는 동안 광점은 공간의 중심으로 이어지고, 입자장과 성운의 배율이 커집니다. 화면이 완전히 연결된 뒤 v5의 시청각 타임라인을 시작합니다. 복귀 시에는 현재 우주의 중심에서 같은 독서 좌표로 되돌아갑니다.

문장 아래의 광점은 저장/참여 기능이 아닌 일시적인 장면 전환 장치입니다. 별을 남겼다는 완료 표시나 카운터는 없습니다.

목차 패널에 남아 있던 밝은 배경과 주황색 선택 텍스트를 제거했습니다. 독서 페이지, 설정, 이동 패널은 공통 표면·본문색·보조색·구분선 변수를 사용합니다. 우주 아트워크의 빛 색은 그대로 유지했습니다.

사운드는 기본 켜짐이며, 실제 재생은 브라우저 허용 범위를 따릅니다. UI에 별도의 음악 시작 안내 화면을 추가하지 않습니다.
